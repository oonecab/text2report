# 字段不匹配问题

**发现时间**：2026-04-16 20:08:00
**涉及表**：dim_org
**所在文件**：`backend/src/main/resources/schema-business.sql:5`, `backend/src/main/java/com/text2report/domain/business/entity/DimOrg.java:12`

## 问题描述
M10 计划要求 `syncFromBusiness()` 按 `id, org_name, parent_id, org_level, org_code, is_active` 从业务库 `dim_org` 同步到元数据库，并保持字段一一对应。但仓库当前业务库参考 schema 和现有实体仍使用旧结构：`parent_org_id`、`parent_org_name`、`status`、`created_at`，且没有 `parent_id`、`is_active` 字段，命名和语义均与 M10 清单不一致。

## 预期字段
`id`, `org_name`, `parent_id`, `org_level`, `org_code`, `is_active`

## 实际冲突
- 已通过真实业务库查询确认 `dim_org` 实际字段为：
  - `id`
  - `org_name`
  - `parent_id`
  - `org_level`
  - `org_code`
  - `is_active`
- 仓库中的旧参考文件 `schema-business.sql` 与旧版 `DimOrg.java` 曾保留历史字段 `parent_org_id`、`parent_org_name`、`status`，与真实业务库不一致
- 已按真实数据库字段修正业务库侧 `DimOrg.java`，`OrgService.syncFromBusiness()` 当前也按真实字段读取

## 影响范围
