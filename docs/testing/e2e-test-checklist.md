# Text2Report E2E 验收清单

> 更新日期：2026-04-12
> 说明：本清单已按真实后端联调后的接口契约整理完毕。当前仓库已完成代码级联调、后端测试与前端生产构建验证；以下场景仍需在具备 PostgreSQL / Redis / LLM 配置的真实环境中逐项勾选。

## 1. 认证流程
- [ ] 管理员登录 `admin/admin123` 成功，显示管理菜单
- [ ] 普通用户登录 `user/user123` 成功，不显示管理菜单
- [ ] 错误密码返回友好错误提示
- [ ] Token 过期后自动跳转登录页
- [ ] 登出后 Token 失效，再次访问需重新登录

## 2. 查询主链路
- [ ] 输入“子公司A 2024年第一季度各部门毛利率”后返回表格、图表与摘要
- [ ] 输入“各产品线2024年收入趋势”后推荐折线图
- [ ] 输入“各渠道收入占比”后推荐饼图
- [ ] 输入“2024年各部门经营明细”后推荐表格
- [ ] 输入“删除所有数据”后被 SQL Guard 拦截
- [ ] 重复相同查询时 Redis 缓存命中，响应时间明显下降

## 3. 管理域功能
- [ ] 组织树展示完整层级结构
- [ ] 组织节点编辑成功并正确回显
- [ ] DDL 上传解析预览正确
- [ ] DDL 确认入库后元数据表更新
- [ ] 术语词典 CRUD 正常
- [ ] JOIN 关系 CRUD 正常
- [ ] 示例对 CRUD 正常
- [ ] 审计日志分页正常
- [ ] 审计统计卡片数据正确

## 4. 历史 / 反馈 / 收藏
- [ ] 历史记录列表正确展示
- [ ] keyword 搜索过滤生效
- [ ] 历史详情抽屉中的 SQL / 摘要 / 审计信息正确
- [ ] 复用历史查询可回填到 Query 页面
- [ ] 提交反馈成功写入审计日志
- [ ] 普通用户、经理、管理员登录后侧边栏均可见“我的收藏”
- [ ] 首次完成查询后，结果卡片右上角出现“收藏查询”按钮
- [ ] 点击“收藏查询”后按钮切换为“已收藏”，并提示“已加入收藏”
- [ ] 已收藏结果再次点击后成功取消收藏，并提示“已取消收藏”
- [ ] 收藏成功后“我的收藏”页立即可见对应问题、组织、图表类型、收藏时间
- [ ] 在收藏页点击“重新执行”后跳回 Query 页面并带入原问题
- [ ] 在历史页复用一条已收藏记录后，Query 页面仍显示“已收藏”状态
- [ ] 非管理员在查询结果页仍不可见 SQL，但不影响收藏操作
- [ ] 取消收藏后收藏页移除对应记录，Query 页面状态同步变为未收藏
- [ ] 对不存在的 request_id 调用收藏接口时返回 404/业务错误提示
- [ ] 用户无法收藏或取消收藏其他用户的查询记录
- [ ] 查询失败、低置信度、无结果时不出现异常的收藏状态串扰

## 5. 错误与边界
- [ ] LLM 服务不可用时返回友好错误提示
- [ ] SQL 执行超时时返回超时提示
- [ ] 空结果集时正确显示“无数据”
- [ ] 超长问题输入时前后端不崩溃
- [ ] 并发请求时不串数据
- [ ] Redis 不可用时降级为不缓存且功能正常

## 6. 验收前置条件
- [ ] `frontend/.env.development` 已设置 `VITE_USE_MSW=false`
- [ ] 后端数据库、Redis、LLM 配置完整
- [ ] `mvn -q test` 通过
- [ ] `npm run build` 通过

## 7. 收藏功能接口测试矩阵
- [ ] `POST /api/v1/query` 返回 `request_id`，且默认 `is_favorited=false`
- [ ] 非管理员调用 `POST /api/v1/query` 时 `sql` 为空，但 `is_favorited` 字段仍返回
- [ ] `POST /api/v1/query/{requestId}/favorite` 首次调用返回 200
- [ ] 重复调用 `POST /api/v1/query/{requestId}/favorite` 为幂等成功或明确返回业务提示
- [ ] `DELETE /api/v1/query/{requestId}/favorite` 返回 200，收藏时间被清空
- [ ] 重复调用 `DELETE /api/v1/query/{requestId}/favorite` 不应污染其他记录
- [ ] `GET /api/v1/query/favorites` 仅返回当前登录用户收藏
- [ ] `GET /api/v1/query/history` 中 `is_favorite` 与 `response.is_favorited` 保持一致
