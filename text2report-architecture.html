Text2Report 系统架构设计文档

自然语言驱动的企业报表平台 — 前后端分离 · React + Ant Design · Spring Boot + 微服务

一、系统总体架构

系统按照「两域分离」设计：财务人员查询域（用户端）和管理员操作域（后台管理端）共享底层微服务，通过 API Gateway 统一接入，前后端完全分离。

四条不可违反原则

1
LLM 只能看到元数据（表名、字段、注释、术语），绝不接触真实业务数据
2
只有查询网关（SQL Guard）可以访问 SQL Server，前端和 LLM 服务禁止直连
3
生产环境只允许只读 SQL（SELECT），通过 JSqlParser AST 解析强制校验
4
每一次请求都必须记录完整审计日志：请求 ID、用户、组织、Prompt、SQL、耗时、行数

2.2 前端核心设计原则

纯渲染，零业务逻辑
前端不做任何 SQL 拼接、指标计算或数据转换。所有业务逻辑由后端处理，前端只渲染 QueryResponse 中的结构化 JSON。
按域拆分路由
查询域 /query/* 和管理域 /admin/* 使用不同 Layout，通过 AuthGuard 按角色控制访问。普通用户看不到 SQL 和管理入口。
组织上下文全局可用
通过 useOrgStore 管理当前选中的组织节点，所有查询请求自动携带 orgId，组件通过 OrgSelector 切换范围。
API 层统一封装
request.ts 封装 axios 实例，自动附加 JWT Token、处理 401 跳转、统一错误提示、注入 requestId 用于链路追踪。

三、后端微服务架构设计

SPRING BOOT + SPRING CLOUD + NACOS

后端采用 Spring Boot 3.x + Spring Cloud 微服务体系，通过 Nacos 实现服务注册与配置管理，各服务独立部署、独立扩展。服务间通过 OpenFeign 进行同步调用。

四、查询域详细流程

1
用户输入
React QueryInput 组件 → 自然语言 + 组织范围选择 → POST /api/v1/query
2
网关鉴权 + 路由
Gateway 验证 JWT → 注入 traceId → 转发到 query-service
3
解析组织上下文
调用 org-service → 查询 org_tree 获取该节点及所有子节点 ID 列表
4
检索元数据
调用 metadata-service → 根据问题关键词检索相关表/字段/术语/JOIN/示例
5
拼装 Prompt + 调用 LLM
PromptAssembler 读取模板文件 → 注入元数据 JSON + 组织上下文 → 调用 llm-service → 返回结构化 JSON（含 SQL）
6
SQL 安全校验
调用 sql-guard-service → JSqlParser AST 解析 → 只读校验 → 自动注入 TOP 1000 + 超时 → 权限范围校验（org_id IN 子句）
7
执行 SQL
QueryExecutor → SQL Server 只读连接池 → 分页 → Redis 缓存（相同查询复用）
8
结果渲染
ResponseAssembler 组装 → 表格数据 + 图表推荐 + 文字摘要 → React 前端渲染
9
审计记录
异步调用 audit-service → 记录 requestId、用户、组织、Prompt 摘要、SQL、耗时、行数、置信度

重试机制：SQL 执行或校验失败时（字段不存在、方言错误等），OrchestratorService 最多重试 2 次，每次将错误信息追加到 Prompt 中让 LLM 修复 SQL。权限拒绝或策略拒绝不重试。

8.2 关键设计模式

策略模式 — LLM 提供者
LLMService 接口 + 多个实现类（OpenAI / Qwen / 未来其他模型），通过 Nacos 配置 llm.provider 热切换，零代码改动。
责任链模式 — SQL 校验
SqlGuardService 内部维护校验规则链：ReadOnlyRule → BlockedKeywordRule → DialectRule → TopInjector → TimeoutInjector。新增规则只需实现接口并注册。
模板方法 — 查询编排
OrchestratorService 定义标准编排步骤（解析 → 检索 → 生成 → 校验 → 执行 → 组装），每步可独立测试和替换。
策略模式 — DDL 解析器
DDLParserService 内部维护多个解析器（InlineComment / ExtendedProperty / CommentOn），按优先级依次尝试，新增注释格式只需添加解析器。
